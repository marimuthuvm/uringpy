In check 7, "default" is the package's own pool, with URINGCORE_BUFFER_COUNT not
set.

Reading. With either pool the server answered a number of requests close to the
size of the pool and then reported that no buffer was available, on one
connection as well as on 400. We did not look for the cause in the package.
uringcore 0.9.1 states that it is tested on Python 3.10 to 3.13; these checks
ran it on 3.14. Nothing here says anything about the package on the versions
it supports.
